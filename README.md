# SQL Lab · SQL 八周训练营

当前版本 **3.0.0**，构建 **20261026.8**。沿用前三批的判分、进度与 PWA 能力，增加任务式首页、应用导航和专注练习；底部导航进一步降低底色与模糊强度，反光集中在玻璃边缘，图标与文字随下方内容明暗调整。应用为单 HTML 文件，42 道题、28 节课程、SQLite/WASM、图标均保留在文件内；直接打开 `index.html` 即可离线学习。

## 学习工作台

「今天」优先继续未完成周测或上次学习，同时展示当周打卡和微课、复习、自由练习入口。八周路径支持直接进入对应阶段；完整的 42 道题放在「按周选择题目」中展开。

顶栏搜索可直达页面、题目、课程与模板，也支持 `⌘ / Ctrl + K`。页面内返回与浏览器前进后退沿用同一学习位置，切换一级页面会恢复各页的滚动位置。练习时可进入「专注练习」收起侧栏、目录与底部导航，再次点击或按 `Escape` 退出；解题笔记按需展开并自动保存。

## 安装与离线

通过 HTTPS 或 localhost 打开，进入「我的 → 安装与离线」。iPhone / iPad 使用 Safari 的「分享 → 添加到主屏幕」；支持安装事件的浏览器也提供「安装 SQL Lab」按钮。主屏名称为 SQL Lab，应用身份固定为 `/sql-trainer/`。启动地址与缓存范围使用部署目录的相对路径，兼容 GitHub Pages 的 `/sql-trainer/` 子路径。

安装前先导出进度备份。浏览器与主屏应用的本地存储可能独立，安装后固定使用同一入口。只有显示「此版本已可离线使用」后，才表示当前构建的 HTML、manifest 和图标已完整缓存。删除浏览器存储仍会影响本机进度，离线副本不能替代备份。

提醒开启前会说明：仅在应用打开期间，到点且当天未练习时通知；关闭应用后没有后台定时提醒。

## 更新规则

「我的 → 关于与版本更新 → 检查更新」直接联网获取 `release.json`，核对版本、构建号与 HTML 的 SHA-256；不会依据 Service Worker 没有变化就宣称已是最新版。离线、请求失败、文件不匹配或发布资源不完整分别保留当前状态，允许重试。

新版离线包通过全部资源校验后等待接管。点击「保存并更新」才切换，切换前保存 SQL、笔记、学习进度与原周测截止时间；保存失败时留在当前页面。其他已打开标签页继续学习。断网或服务端 HTTP 错误时使用完整离线副本，带查询参数的根地址及 `index.html` 入口共用同一副本。未知路径不会被错误替换为 HTML。

缓存按应用目录隔离，只清理本应用的旧版本；`release.json` 始终联网核验，不提供缓存的“最新”结论。旧版已安装用户应联网完整打开一次，再确认当前构建已可离线使用。

## 可重复的发布验收

需要 Node.js、Python 3、Chrome 和已有 Playwright CLI 缓存中的浏览器引擎。验收脚本直接驱动隔离的 Chrome；应用运行本身不需要这些工具或 npm 依赖。

1. 修改应用时，保持 `index.html` 中版本 / 构建元数据与 `APP_VERSION` / `APP_BUILD` 一致，更新日志同步。递增 `sw.js` 的缓存代号、版本与构建；发布构建号不可复用。
2. 更新校验清单：`node scripts/release.cjs --write`。只有更换应用图标时才使用 `--icons --write`；图标 PNG 由内置绘制逻辑生成，无外部依赖。
3. 本地完整验收：`./deploy.sh --check`。脚本启动临时 localhost 服务，依次执行版本 / SHA-256 / 图标 / 单文件语法、37 个可靠性检查以及学习、模拟同步、手机布局和 PWA 发布回归。结果写入 `output/release/acceptance.json`，失败会返回非零退出码。
4. 如仅需快速检查代码与资源，使用 `python3 scripts/verify-release.py --static`；报告明确标记为 `static`，不能代替完整浏览器验收。
5. 确认需要对外发布后，由用户执行 `./deploy.sh --publish`。它重新完整验收，只提交列明的应用、脚本与测试路径，再推送到指定 SQL 仓库；默认运行只验收。发布脚本不复制外部 HTML，也不加入截图、浏览器日志和其他无关文件。

线上发布后使用部署地址核对构建号、检查更新、主屏入口、离线关闭再打开、SQL 草稿和周测恢复、备份导入。另用真实 iPhone 验证安装图标、软键盘和 VoiceOver。浏览器模拟通过不等于完成这些真机验收。

第三批保留全部原图标中实际使用的 67 个图标，SVG 路径与原库一致；SQL 引擎、题库与课程内容保持第二批版本。详细用例见 `tests/README.md`。

实现参考：Web App Manifest 的 id 规则见 [MDN](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Manifest/Reference/id)，更新时机与生命周期见 [web.dev](https://web.dev/learn/pwa/update)。
