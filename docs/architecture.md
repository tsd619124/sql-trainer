# SQL Lab 4.0 应用设计与工程结构

本版从主仓库 3.0.0（f7ff9ed）迁移，保留八周路径、42 道 SQL 题、28 节微课、解析、模板及已有学习闭环。Web 与 iOS 共享内容、判分和界面，iOS 使用 Capacitor 承载应用，并通过 Swift 接入设备能力。

## 产品结构

| 一级页面 | 主要任务 |
| --- | --- |
| 今天 | 继续上次学习、恢复周测、查看打卡、进入学习路径与到期复习 |
| 训练 | 微课、学习计划、SQL 练习、自由练习、间隔复习、模板、数据表 |
| 测验 | 限时周测、结果与错题重练 |
| 我的 | 学习档案、成就、主题字号、提醒、备份、同步、版本与离线状态 |

全局搜索、返回、滚动位置、专注练习和无障碍交互沿用第四批实现。电脑和手机使用同一套响应式布局，手机编辑时收起底部导航。

## 源码职责

| 路径 | 职责 |
| --- | --- |
| `app/src/content/catalog.js` | 稳定 ID 的题库、课程、学习路径、解析和模板 |
| `app/src/domain/progress.js` | 进度校验、修订时钟、删除标记、合并与恢复 |
| `app/src/domain/grading.js` | 结果归一化、有序及无序结果比较 |
| `app/src/engine/dataset.js` | 可重复生成的练习数据，每次建库重新使用相同随机种子 |
| `app/src/engine/judge.js` | 每次判题创建独立只读数据库，拒绝写入和多语句 |
| `app/src/engine/runtime.js` | 加载安装包或站点本地的 SQL.js / WASM |
| `app/src/services/storage.js` | Web / iOS 存储接口、原生写入队列、失败重试与迁移 |
| `app/src/services/sync.js` | 自配 Gist / LeanCloud、AES-GCM、记录级同步 |
| `app/src/platform/device.js` | Swift 桥接、提醒、分享、触感与应用生命周期 |
| `app/src/platform/updates.js` | Web 安装、完整离线包校验、保存后更新、iOS 更新说明 |
| `app/src/app/workspace.js` | 学习会话、各页面呈现和操作协调 |
| `app/src/styles/` | 从 3.0 拆出的基础、手机和工作台样式 |
| `ios/App/App/` | iOS 入口、Swift 插件、图标、启动页及原生项目配置 |

`app/index.html` 只承担页面壳和应用入口。旧的根目录 `index.html` 保留为 3.0 兼容文件，新版由 `npm run build` 生成到 `dist/`，不再将源码拼回单文件。

## 学习数据

Web 继续采用已有的 `sqltrain_*` 存储键，保留同源升级与浏览器跨标签页同步。站点换域名、`file://` 改为站点、Web 转 iOS 均需要导入备份，或在两端配置同一个同步服务。

iOS 常规学习数据写入 Application Support 下的 `SQLLab/learning.json`，文件以原子替换方式保存；本机同步配置单独进入 Keychain，不写入该 JSON 文件，也不混入学习备份。WebView 缓存仅在原生存储首次初始化时用于迁移，已删除的原生设置不会从旧缓存复活。

草稿、周测试卷和截止时间保存在本机学习会话中，学习进度按原 v1 备份格式迁移。导入仍完整校验，覆盖与清空仍先保存应急备份，删除记录仍参与同步合并。

本机文件写入失败会保留待写入内容并提示；备份分享仍可从当前学习进度生成，不依赖磁盘写入重试成功。切换 Web 新版前必须完成进度与会话保存。

## 设备能力

iOS 使用系统通知预排未来 30 天的提醒，每次打开、修改时间或完成当日训练后重新安排；已经练习的当天不再排提醒。授权由用户点击开启触发。Web 提醒保持应用打开期间有效。

iOS 备份进入系统分享菜单，可保存到文件或选择其他分享目标；导入使用系统文件选择器。触感反馈使用系统轻触反馈，前后台切换会保存会话并按原截止时间恢复周测。

## 构建与发布

Vite 将源码构建为有哈希文件名的模块和样式。SQL.js、WASM、图标随构建提供，无外部 CDN 运行依赖。构建同时生成 `release.json` 与 Service Worker；清单记录每项资源的 SHA-256。全部资源通过校验后才形成离线包，新版等待用户保存并切换。

相对资源路径支持部署在 `/sql-trainer/` 等子目录。Web 与 iOS 使用相同的 `dist/`，`npm run ios:sync` 将已构建的内容同步到 Xcode 工程。

## 范围与验收

这是面向个人学习的离线应用，保留自配云同步；本版没有新增账号服务器、付费服务、题库管理后台或由开发者托管的学习数据服务。

验收分为模块测试、浏览器学习与布局回归、多文件 PWA 验证、原生桥接模拟、Swift / 项目静态检查和真实 iOS 构建。模拟桥接不等于运行过 Swift，语法检查不等于 iOS 编译。是否完成模拟器构建，以 `output/release/ios-acceptance.json` 中的 `nativeBuild` 字段为准。
