# SQL 训练系统回归验收

第一批基线：2.7.0（2026-10-26）。修改范围为审查第 1–5 项，保留 42 道题、28 节课程及内嵌 SQL.js/WASM 和图标库。

## 本地回归

无需安装项目依赖：

```sh
node --test tests/reliability.test.cjs
node --check sw.js
```

37 个检查覆盖排序与并列行、备份结构校验、旧数据兼容、删除标记、清空与回滚屏障、合并性质及所有内联脚本语法。

## 浏览器回归

需要 Node.js、Python 3、Chrome 和已有 Playwright CLI 缓存中的浏览器引擎。先在源码目录启动 HTTP 服务：

```sh
python3 -m http.server 8644 --bind 127.0.0.1
```

另开终端，在源码目录执行：

```sh
python3 tests/run-browser.py http://127.0.0.1:8644/
```

执行器复用已有 Playwright 引擎，直接启动隔离的 Chrome；每套用例使用新的浏览器和存储环境，结束时关闭本次浏览器。可以在 URL 参数后传入脚本名只运行指定用例；默认依次运行可靠性、模拟同步、手机体验、PWA 生命周期和旧版 SW 迁移五套回归。Gist 和 LeanCloud 请求全部被浏览器拦截，以虚拟凭证和独立设备存储验证实际同步入口、AES-GCM 加解密及补推逻辑。

`reliability.browser.js` 包含 11 组流程：

- 42 道标准答案全部通过；危险 SQL 和多语句被拒绝。
- 普通练习拒绝逆序，允许排序键并列行换序。
- SQL 草稿、空草稿、笔记、题号、学习子页和课程位置刷新恢复。
- 自由练习删表不影响判题和课程数据；重置后恢复初始库。
- 无效进度码与文件不改变原数据；旧版 JSON/base64 可导入。
- 较旧快照可以回滚，导入和清空可通过应急备份恢复。
- 存储空间不足时导入不半替换。
- 周测试卷、答案、题号和截止时间保持；新试卷不沿用旧答案。
- 关闭期间超时自动交卷，重复刷新不重复增加错题。
- 390px 和 1440px 主要页面可用；离线重开仍可判题。

`sync.browser.js` 对 Gist、LeanCloud 各验证 5 组流程：笔记新修改、删除不复活、仅尝试次数和复习安排变化的持久化、无效云载荷停止上传、同步中修改补推及加密读写。

第一批验收记录：通过 37 个本地检查、42 道参考答案、11 组浏览器流程和两种服务的 10 组模拟同步流程。浏览器运行未捕获脚本异常或非预期的控制台错误与警告；同步测试主动屏蔽 Service Worker 所产生的 Playwright 提示单独排除。未使用真实云账号，也未在 iPhone 真机验证。

## 数据与同步规则

保留 v1 备份格式，新增 `_sync` 记录修订与删除标记；旧备份在读取时补齐。相同记录保留最新修订。清空、覆盖恢复和回滚建立同步屏障，避免旧设备带回已清除的进度。各设备使用新版后才能一致执行删除规则。

草稿和周测会话只存于本机 `sqltrain_session`，不上传。导入或清空前保存一份应急进度与会话，可在「我的 → 备份与迁移 → 恢复导入或清空前进度」恢复。第二批 Service Worker 缓存版本为 `sql-trainer-v21`；第三批递增至 `sql-trainer-v23` 并按部署目录隔离。本地迭代不代表已部署或推送。

| 审查项 | 实现与验收重点 |

| 7 编辑与反馈 | 关键字与符号按光标插入并保存，括号与引号定位到中间；编辑器可展开本题表结构。失败提示缺失、多余记录或排序差异，通过后可下一题、复习或结束。闭卷周测只提供输入快捷键。 |
| 8 表格布局 | 数据表、课程示例和查询结果采用具名、可聚焦的局部滚动容器，表头声明列作用域；页面不跟随宽表横向扩张。 |

| 12 内容与操作层 | 正文、表格与卡片使用稳定的实色内容面；导航保留玻璃材质，字号与内容间距统一使用语义变量。 |
