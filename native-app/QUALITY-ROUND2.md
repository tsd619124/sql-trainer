# 第二轮产品完整性修复

日期：2026-10-27。基线为第一轮修复后的 SQL Lab 5.0.0（10）原生 App。沿用四个主导航、42 道 SQL 题、28 节课程和 9 个模板。

## 本轮交付

| 功能 | 实际行为与入口 |
| --- | --- |
| 今日学习任务 | 首页优先展示当前阶段、课程、练习和到期复习。支持最多 15 分钟的短时任务与按每日预算安排的完整任务；任务在当天保持稳定，完成后不立即换成新题，次日接续未完成项。复习不会因选择较晚起点而消失。 |
| 学习状态分层 | 课程标记为“已阅读”，配套练习单独显示独立通过数。题目区分辅助完成、独立完成、复习通过和稳定掌握；不同日期第二次独立通过计为复习通过，第三次计为稳定掌握，同日重复不升级。 |
| 入门诊断与路径 | 首页和个人页均可设置基础、目标、每日 15/30/60 分钟、起点和跳过选项。4 道真实 SQL 诊断覆盖取数、聚合、JOIN、窗口函数；结果建议起点，允许自行调整，不自动写入任何掌握记录。 |
| 周测历史与复盘 | 测验页保留历次周测，提供题目分值、实际用时、按能力统计的失分、每题错误原因、原作答与独立复练。未作答单独标记，保存成绩与清除活动考试会话为同一次原子写入；考试 ID 防重复交卷。旧版只有上次成绩的记录仍可查看，未记录的用时与原因不推算。 |
| 学习能力档案 | 个人页展示取数、聚合、JOIN、子查询/CTE、窗口函数、业务综合六类能力。独立通过率按本轮开始记录的独立作答次数计算，辅助作答不进入分母；同一题累计失败至少 2 次列为重复错误，并提供重练入口。 |
| 数据与同步中心 | 个人页显示最近成功导出、最近成功同步、待同步与失败原因。上传只确认上传时的快照，上传过程中发生的新学习继续待同步。导入/合并前自动创建本机恢复点，也可手动创建；恢复包含草稿并生成新的修订，恢复前再次保留当前数据。 |
| 提醒时间回显 | 优先读取系统已排定的每日通知，其次读取持久化的小时和分钟；首次默认 20:00。关闭提醒保留上次设定时间，重新打开设置或重开 App 不再使用当前时刻替代已设时间。 |

## 证据与兼容

- 独立作答证据使用独立事件 ID 保存，跨设备合并不会把两端各自的事件当作同一计数覆盖；能力档案不再依赖只保留 12 条的运行历史。
- `learningProfile`、`evidence`、`tests` 随学习进度备份与同步。备份不含认证信息、本机草稿、同步确认元数据或恢复点文件。
- 保持 v1 基础格式及原题目、课程 ID。共享 Web 进度解析与合并模块同步接入可选新字段，未重设计 Web 页面；新增跨语言样本核对 Swift 与 JavaScript 的归一化、合并及删除修订。
- 旧版学习备份可继续导入。新字段需要另一端升级到本轮兼容实现；此前发布的旧客户端不能视作已支持这些记录。本轮未发布 Web 或分发新的真机安装包。
- 每日任务属于本机学习会话；学习路径、作答证据与周测成绩属于可同步学习进度。更改路径会重新安排当天任务，不标记被跳过的内容已掌握。
- 短时任务遵守 15 分钟预算；完整任务遵守设定的每日时间。预算较少或没有到期题时，不强制凑齐三种任务。所示分钟数为课程时长与练习/复习预估，不承诺实际完成时间。
